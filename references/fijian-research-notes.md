- drokadroka = green
- dromodromo = yellow
- karakarawa = blue

- seninawanawa = orange

**PolyglotClub set (FLAGGED AS ERRONEOUS):**

- iro = black
- lolo = red
- wailevu = green

Sources: PolyglotClub [4] only

**Why PolyglotClub is rejected:**
1. Glosbe [10] confirms "drau" means "leaf/needle" and "100/hundred" — NOT white
2. The word "loaloa" (black) is corroborated by 101 Languages AND Quizlet
3. The word "vulavula" (white) is corroborated by 101 Languages, Quizlet, AND a YouTube song ("Vulavula is White" by Pasifika Beatz)
4. PolyglotClub's color set has no corroboration from any other source

## Pronunciation Guide

### Vowels (like Spanish/Italian/German)
- a = /ah/ (as in "father")
- e = /eh/ (as in "error")  
- i = /ee/ (as in "see")
- o = /oh/ (as in "go")
- u = /oo/ (as in "food")

### Tricky Consonants
- c = /th/ (as in "thin") — NOT "see"
- q = /ng/ (as in "sing") — only in borrowed/proper names
- d = /nd/ (soft d before consonants becomes n)
- g = /ng/ (as in "finger")
- b = /mb/ (almost always preceded by m)

### Other Notes
- Long vowels: aa, ee, ii, oo, uu (stress on long vowel)
- Stress: usually penultimate (second-to-last) syllable
- Glottal stop: written as apostrophe (')
- Double consonants (dr, gr, tr) are single sounds

## Grammar Notes

### Word Order
- Basic: Subject + Verb + Object
- Pronouns as subject markers: "Au" = I, "Iko" = you
- "E" marks inanimate subjects, "O" marks proper nouns/pronouns

### Articles
- "E" for inanimate common nouns
- "O" for proper names and pronouns
- "Na" before nouns = "the" (definite article)

### Possession
- Possessive pronouns: noqu (my), nomu (your), nona (his/her)
- Family terms use '-qu' suffix: tinaqu (my mother), tamaqu (my father)
- Possession structure: [possessor] + [classifier] + [possessed]

### Numbers
- 1: dua, 2: rua, 3: tolu, 4: va, 5: lima
- 6: ono, 7: vitu, 8: walu, 9: ciwa (pronounced "thi-wa"), 10: tini
- 11-19: tini ka [number], e.g., tini kadua (11), tinikarua (12)
- 20: ruasagavulu (two-ten)
- Ordinals: prefix "i'a-" to numbers, e.g., i'arua (second)

### Questions
- "cava" = what (C pronounced "th")
- "cei" = who
- "ko" = where/this place
- "naica" = when
- "e vica" = how many/much
- "vakacava" = how

- tinaqu = mother (my mother)
- tamaqu = father (my father)
- luvequ tagane = son
